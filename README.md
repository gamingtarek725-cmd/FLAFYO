# FLAFYO GAME TRANSLATOR

**مترجم ألعاب لنظام Windows** — ترجمة نصوص الشاشة، إدارة إعدادات كل لعبة، وفحص ملفات الألعاب مع الحفاظ على الملفات الأصلية.

[تحميل أحدث إصدار Windows مباشرة](https://github.com/gamingtarek725-cmd/FLAFYO/releases/latest/download/FLAFYO-GAME-TRANSLATOR-Setup.exe) · [سجل الإصدارات](https://github.com/gamingtarek725-cmd/FLAFYO/releases) · [خارطة الطريق](docs/ROADMAP.md)

## أحدث إصدار منشور

- الإصدار المستقر الحالي: **v0.3.4**.
- [تحميل المثبّت مباشرةً (Windows x64)](https://github.com/gamingtarek725-cmd/FLAFYO/releases/latest/download/FLAFYO-GAME-TRANSLATOR-Setup.exe).
- [صفحة الإصدار وسجل التغييرات](https://github.com/gamingtarek725-cmd/FLAFYO/releases/latest).
- رابط التحميل المباشر أعلاه يتجه تلقائيًا إلى أحدث إصدار منشور، ولا يشير إلى ملفات CI المؤقتة.

## المزايا الموجودة في المشروع

### الترجمة أثناء اللعب
- التقاط منطقة من الشاشة وتشغيل OCR عبر مكوّن Windows.
- عرض الترجمة في نافذة Overlay مصممة لتقليل حجب التفاعل مع اللعبة.
- خط معالجة منفصل مع قائمة إطارات محدودة، وإسقاط الإطارات القديمة عند وصول إطار أحدث.
- ذاكرة مؤقتة للترجمة وقواميس ومصطلحات ألعاب.
- دعم مسارات ترجمة محلية عبر حزم النماذج، إضافة إلى موفّرات ترجمة عبر الإنترنت أو API عند إعدادها.
- حزمة MADLAD-400 3B INT4 غير متاحة حاليًا من واجهة التطبيق؛ ملفات ONNX المتاحة لا تطابق بنية Decoder التي يتوقعها محرك التشغيل. لن يظهر النموذج كخيار قابل للتنزيل أو الاستخدام حتى دمج تصدير متوافق واجتياز اختبارات ترجمة فعلية.

### إدارة الألعاب
- إعدادات منفصلة لكل لعبة، تشمل منطقة الالتقاط والمظهر وخيارات الترجمة.
- حفظ ذري للإعدادات وملفات تعريف الألعاب مع نسخة `.bak` واستعادة تلقائية عند تلف ملف JSON الأساسي.
- استيراد وتصدير ملفات إعدادات اللعبة بصيغة JSON.
- التحقق من القيم، ورفض الملفات غير الصالحة أو الأكبر من 256 كيلوبايت.
- الاحتفاظ بنسخة احتياطية عند استبدال إعدادات موجودة.
- عدم تفعيل التشغيل التلقائي المستورد دون سؤال المستخدم.

### فحص ملفات الألعاب
- تحليل ملفات اللعبة واستخراج النصوص المدعومة.
- أدوات حاويات ARC وZIP، بما في ذلك ملفات ZIP ذات امتداد مختلف مثل بعض ملفات PAK.
- إعادة بناء نسخة منفصلة والتحقق منها قبل السماح بالتطبيق.
- تعديل نصوص ثنائية محددة الطول على نسخة عمل، مع التحقق من الإزاحة والترميز وعدم تداخل التعديلات.
- حدود للحجم وعدد العناصر، وحماية من مسارات الاستخراج غير الآمنة.
- إنشاء نسخ احتياطية وعدم تعديل ملفات اللعبة الأصلية أثناء الفحص أو البناء.

### مكتبة التعريبات
- فهرس لمصادر تعريبات الألعاب وروابطها الأصلية.
- تحديث دوري للفهرس عبر GitHub Actions.
- قد تختلف البيانات المتاحة من مصدر لآخر؛ الحقول غير المتوفرة لا ينبغي اعتبارها مؤكدة.
- لا يعيد المشروع استضافة ملفات التعريب المجتمعية دون إذن أصحابها.

## التثبيت والتحديث

1. نزّل ملف التثبيت من صفحة الإصدار.
2. شغّل المثبّت واتبع التعليمات.
3. عند توفر إصدار أحدث، استخدم محدّث التطبيق أو نزّل المثبّت من صفحة الإصدارات.
4. لا تحذف مجلد بيانات المستخدم يدويًا إذا كنت تريد الاحتفاظ بالإعدادات والقواميس والسجل.

## البناء والاختبارات للمطورين

المتطلبات:
- Windows مع .NET 8 SDK.
- مستودع المشروع كاملًا.

تشغيل الاختبارات:

```powershell
dotnet test tests/Flafyo.Core.Tests -c Release
```

بناء التطبيق:

```powershell
dotnet publish src/Flafyo.App/Flafyo.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

يتم بناء مُثبّت Windows عبر Inno Setup ضمن مسار الإصدار في GitHub Actions. راجع [ملف سير العمل](.github/workflows/release.yml).

## حدود معروفة وما لم يتم اعتماده بعد

- نجاح الاختبارات والبناء في GitHub Actions لا يثبت التوافق مع كل لعبة أو كل وضع عرض.
- اختبار القبول داخل ألعاب فعلية، وقياس زمن OCR والترجمة واستهلاك الموارد على أجهزة مختلفة، ما زال مطلوبًا.
- لا يُعلن دعم صيغة أرشيف لمجرد تشابه امتدادها؛ يلزم ملف عينة واختبار استخراج وإعادة بناء.
- لا تستخدم خيار تطبيق أرشيف مُعاد بناؤه على ملفات مهمة قبل الاحتفاظ بنسخة احتياطية مستقلة.
- دقة الترجمة تختلف حسب النموذج والمصدر والسياق، ولا يوجد ضمان بزمن استجابة فوري أو انعدام التأخير.
- لا تتوفر حزمة MADLAD للتشغيل في الإصدار الحالي؛ راجع قسم البحث المستقبلي لمعرفة متطلبات إعادة تفعيلها.

## بحث MADLAD المستقبلي

- النموذج الأصلي: [Google MADLAD-400-3B-MT](https://huggingface.co/google/madlad400-3b-mt).
- مصدر تصدير ONNX قيد التقييم: [MADLAD-400-3B-MT ONNX](https://huggingface.co/tonythethompson/madlad400-3b-mt-onnx).
- هذا القسم مرجع بحثي فقط؛ لا يعني أن ملفات النموذج الحالية متوافقة أو قابلة للتشغيل داخل التطبيق.
- قبل إعادة تفعيل الخيار، يلزم التحقق من توافق Encoder/Decoder وTokenizer وملفات الأوزان، ثم اجتياز اختبار ترجمة عربية فعلي وقياس الذاكرة وزمن الاستجابة.

## الأمان والخصوصية

- افحص ملفات الألعاب في وضع القراءة أولًا، واستخدم نسخ عمل عند التعديل.
- لا تشغّل ملفات تنفيذية أو أدوات مجهولة مصدرها أرشيف لعبة.
- مفاتيح API يجب أن تبقى خاصة على جهاز المستخدم؛ لا تضعها في المستودع أو البلاغات أو لقطات الشاشة.
- لا ترسل ملفات ألعاب أو ملفات تعريب محمية بحقوق النشر إلى مصادر خارجية دون التأكد من الإذن وسياسة الخدمة.

## المساهمة والإبلاغ عن مشكلة

عند الإبلاغ عن مشكلة، أرفق إصدار التطبيق، إصدار Windows، خطوات إعادة المشكلة، ورسالة الخطأ ذات الصلة. احذف أي مفاتيح API أو بيانات شخصية من السجلات قبل مشاركتها.

راجع [خارطة الطريق](docs/ROADMAP.md) لمعرفة ما تم تنفيذه وما لا يزال يحتاج إلى اختبار قبول فعلي.
